📊 Project Overview

🎯 Problem

Water-borne diseases (cholera, diarrhea) cause significant health burden. Traditional surveillance is reactive. We need early warning 2-4 weeks ahead.

💡 Solution

ML model using Logistic Regression with 13 features (rainfall, past outbreaks, seasonality) to predict outbreak risk and flag top 20% districts weekly.

📈 Performance

Catches 55.6% of outbreaks (vs 20% random). ROC-AUC 0.724 shows excellent discrimination. 2.8× better than random flagging.

🗂️ Data Sources

  • EpiClim (Zenodo): Historical outbreak data 2009-2022, 700+ districts
  • IMD Rainfall: Daily gridded rainfall (0.25° resolution)
  • IDSP Reports: Weekly outbreak reports from Ministry of Health

🔧 Technical Stack

  • ML Model: Logistic Regression with class balancing
  • Features: 13 engineered (rainfall lags, anomalies, past outbreaks, seasonality)
  • Libraries: pandas, numpy, scikit-learn, streamlit, plotly
  • Dataset: 304,090 district-week observations
